### 🧭 About Me

I don't write code — I **describe problems**, and AI writes the code.

Everything in this profile is a side project built in the gaps between work. Nothing here is a portfolio piece chasing a job title; it's just tools I actually needed, built because the alternative was doing the same boring thing manually for the hundredth time.

```text
🧑‍💻  Background      : Zero. No CS degree, no bootcamp, no formal training.
🤖  Method          : Everything by AI code generation (Claude Code, and friends).
🎯  Why I build     : Personal needs, hobby, and learning — in that order.
⏱️  When I build    : In between work hours. This is my "iseng" project space.
🤝  Open to         : Collaboration, if any of this is useful to you.
```

> **The philosophy:** you don't need to be an engineer to solve your own problems anymore.
> You need to know the problem well enough to explain it clearly. The rest is a conversation with a machine.

### 🎮 Mini Game: Guess the Prompt

Every project here started as a single sentence. Can you guess what the code does?

<details>
<summary>🕹️ <b>Round 1</b> — <i>"Take these spreadsheets, find every row where the promo matches, and tell me how much money we owe."</i></summary>
<br>

**Answer:** A monthly promo claim recap engine — it cross-checks transaction data against promo tables and totals the claim per brand, SKU, and store.

**Before:** a full day of manual cross-checking. **After:** a couple of minutes.

</details>

<details>
<summary>🕹️ <b>Round 2</b> — <i>"Read this sheet and turn every row into a slide that doesn't look like a spreadsheet."</i></summary>
<br>

**Answer:** A deck generator that builds formatted presentation slides straight from tabular data.

**Before:** an entire evening, every month. **After:** one click.

</details>

<details>
<summary>🕹️ <b>Round 3</b> — <i>"I'm going to describe this in Indonesian and you're going to write the JavaScript."</i></summary>
<br>

**Answer:** Literally every repository on this profile. 😄

</details>

### 💡 Lessons From Building Without Code

<details>
<summary><b>Click to open — 5 things nobody tells you</b></summary>
<br>

1. **Describing the problem is the hard part.** The code was never the bottleneck; knowing exactly what "done" looks like was.
2. **Small and ugly beats big and unfinished.** Every tool here started as one function that did one thing.
3. **You will break things.** Version control stops being optional the moment AI can rewrite 400 lines in a second.
4. **Reading code matters more than writing it.** I can't write it from scratch, but I can tell when it's wrong — and that turns out to be enough.
5. **Real usage is the only test that counts.** If I stopped using a tool after a week, it wasn't solving a real problem.

</details>
